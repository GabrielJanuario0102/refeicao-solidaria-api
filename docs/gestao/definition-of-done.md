# FIREFLYTECH — Definition of Done (DoD)

**Proposta de acordo da equipe — revisar e aprovar na Sprint 1.**

## Para uma Task de documentação

- [ ] Texto atende aos critérios de aceitação da atividade Jira.
- [ ] Conteúdo é claro e usa os nomes de perfis/funcionalidades definidos no projeto.
- [ ] Arquivo é salvo em `docs/` (ou `CONTRIBUTING.md`) no repositório apropriado.
- [ ] Há revisão por outro integrante; comentários relevantes foram resolvidos.
- [ ] Jira contém link para o PR ou evidência do documento versionado.

## Para uma Task de código

- [ ] Implementação atende à Task e não inclui escopo de sprints futuras sem acordo explícito.
- [ ] Código executa ou compila no ambiente estabelecido pelo projeto.
- [ ] Testes/lint aplicáveis foram realizados; evidência registrada (comandos e resultados reais).
- [ ] Mudanças são revisadas em Pull Request antes de integrar à `main` (quando o fluxo de revisão for adotado).
- [ ] Arquivos sensíveis (`.env`, senhas, segredos e credenciais reais) não estão versionados.
- [ ] README ou instruções de execução são atualizados quando necessários.

## Para uma Story

- [ ] Critérios de aceitação específicos foram testados ou validados.
- [ ] As Tasks necessárias estão integradas; Tasks independentes não precisam ser forçadas a virar subtarefas.
- [ ] Evidência da validação (documento, link, captura ou registro de teste) foi anexada ou referenciada no Jira.
- [ ] Responsável pela validação confirma o resultado; só então a Story é concluída.
